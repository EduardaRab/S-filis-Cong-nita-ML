# notebooks/

Notebooks Jupyter de análise exploratória e de experimentos rápidos.

- Use nomes com número e autor, por exemplo `01_lucas_exploracao_sinasc.ipynb`.
- Notebooks leem de `data/` e não gravam em `data/raw/`.
- Código que for reaproveitado deve ser movido para `src/`.
- Antes de commitar, limpe as saídas muito grandes (*Kernel > Restart & Clear Output*).
